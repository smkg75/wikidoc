# TRAPS.md — what the corpus contains and what correct handling looks like

Manifest for a grader (human or agent), not a script. There are deliberately
no frozen assertions: run the pipeline over a corpus generated by
`build.py <target>` (with `WIKIDOC_HOME` at a temp dir, never `~/.wikidoc`),
then judge the outcome against this file. `build.py` prints a JSON manifest —
one entry per file with its expected `triage`, plus a `traps` dict recording
which traps the filesystem actually accepted (a case-insensitive volume
collapses the case twins; that is the flag being `false`, not a failure).

All data is invented. The identifiers are fictitious but validator-passing:
SIREN `842931073`, SIRET `53169420600024` (Luhn), IBAN
`FR76 1234 5678 9000 0246 8130 050` (mod-97) — the pipeline must treat them
as real ids without any of them naming anyone.

## Grader setup

The corpus tests nothing until a config points at it. Write a test
config.yaml with: `root` = the corpus dir; `inboxes:` listing `Inbox/`;
identifier patterns with `validate: luhn` / `validate: iban`; a `sensitive:`
block catching ordonnance/passeport/IBAN/bulletin de paie/analyses; two
rules — `rent-receipt` (text "quittance de loyer" →
`Archive/Loyer/quittances-{doc_year}`) and `invoice` (text "facture" →
somewhere under `Archive/`); an `anchors:` file citing one backticked path
that does not exist (to provoke the anchor check). How you check each trap
is your judgement; what "correct" means is below.

## Corpus traps

**NFD filename** (`Traps/facture-électricité-août.txt`, stored decomposed)
— macOS writes NFD, everyone else types NFC. Correct: the file is matched,
routed on its content, and its memory `path` is NFC. Wrong: two memory
lines for one file, or no match because bytes differ.

**Case twins** (`Traps/Casse-Test.txt` / `casse-test.txt`) — on a
case-sensitive volume both exist; the pipeline must keep them distinct (two
memory lines, two entries). On a case-insensitive volume only one survives
(`traps.case_only_names_distinct: false`) and nothing should crash or
double-count.

**cp437 zip** (`Traps/archive-cp437.zip`) — entry names encoded cp437
without the UTF-8 flag. Correct: zip_text decodes or degrades gracefully;
no UnicodeDecodeError, no crash.

**Icon\r** (`Traps/Icon\r`) — a carriage return in the filename. Correct:
walked, recorded, never mangled into a path that breaks routing.json or
memory.jsonl (JSON escapes it fine; shell interpolation does not).

**CON.pdf** (`Traps/CON.pdf`) — a Windows-reserved name. Correct on this
platform: an ordinary residual. The trap fires if code ever builds a
destination named after it on a platform that refuses it — failure must be
a failed entry, not a crash.

**Path over 260 chars** (`Traps/level-00…/document-profond.txt`) — deep
nesting past the classic Windows limit. Correct: extracted, recorded,
moved without truncation.

**200-char filename / zero-byte file** (`Traps/nnn…n.txt`, `Traps/vide.txt`)
— boundary noise. Correct: both survive the walk; the empty file is
`opaque: "no-content"` (size ≤ 1024, no text), never `needs_vision`.

**Typographic apostrophe** (`Traps/Dossier d’archive/note d’honoraires.txt`)
— U+2019 in both directory and filename. Correct: routed on content;
`norm()` bridges pattern vs path; no quoting bug in any shell-out.

**Re-download pair** (`Traps/ohmea-v1.txt` / `ohmea-v2.txt`) — same text,
different bytes (trailing newlines differ). Correct: NOT flagged as
duplicates — dedup is md5, byte-identical only. Both route on content.

**Small byte-identical duplicates** (`Traps/attestation.txt`,
`Docs/attestation-copie.txt`, ~100 bytes each) — pinned v1 bug: a
DEDUP_MIN_SIZE of 4096 made every real duplicate invisible, and the v1
fixture was padded past the threshold to hide it. Correct: grouped as
duplicates with no size threshold, both `propose` (duplicate guard), never
both trashed.

**Dangling symlink** (`Traps/lien-mort.pdf` → missing target) — pinned v1
bug: an unguarded `os.stat` killed the pass. Correct: `lexists` but not
`exists` = a failed entry; collect and apply both continue past it, and if
apply had already moved files, their memory lines are already written
(incremental memory — see below).

**Image-only sensitive scan** (`Inbox/scan-0042.pdf`) — a prescription whose
text is drawn as pixels: readable by vision, empty to extraction. Correct:
collect marks `needs_vision: true` and produces a page-1 render; route
refuses to judge it while text is empty (vision barrier, exit 2); once a
vision agent fills `text` from the render (`lu: "render"`), the sensitive
guard fires → `propose`. A trash decision on it must be REFUSED by apply
unless `reviewed: "vision"` — the probe re-extracts text and ids from the
file itself and finds nothing, and empty text + size > 1024 is exactly the
case v1 trashed blind.

**MM/YYYY receipts** (`Docs/Loyer/quittance-01..05.pdf`,
`Inbox/quittance-avril.pdf`) — pinned v1 bug: the only date in these files
is `MM/YYYY` and v1 could not parse it, so `{doc_year}` never resolved.
Correct: `doc_year` extracted (2025), destination renders
`…/quittances-2025/`.

**Undated receipt** (`Docs/Loyer/quittance-sans-date.pdf`) — same rule, no
date anywhere. Correct: the rule does NOT fire; `propose` with
`why: "destination variable unresolved: doc_year"`. Never an `undated/`
folder, never a silent default year.

**Accented content vs unaccented pattern**
(`Docs/Loyer/quittance-accents.txt`, "Période", "Quittance" mixed case) —
pinned v1 bug: matching was accent-sensitive in one code path. Correct:
every comparison goes through `memory.norm()`; this file matches a rule
written without accents.

**Inbox folder** (`Inbox/`) — a Desktop-like dump listed under `inboxes:`.
Correct: every file in it is `propose`, including `quittance-avril.pdf`
which a rule WOULD route — an inbox is emptied by decision, never silently.

**Already-filed folder** (`Archive/Loyer/quittances-2025/`) — two receipts
already sitting at the destination their rule renders. Correct: no move
(or a no-op), and `--learn`'s shadow comparison counts them as `agreed` —
"already in the right place" is agreement, not a miss.

**Two-entity contract, no shared identifier** (`Docs/contrat-cadre.txt`) —
two entities named in text, neither with an identifier, equal strength-2
evidence. Correct: entity tie → `propose`. No arithmetic tiebreak; only
reading (the decide agent) picks.

**Sensitive plain-text set** (`Perso/passeport-scan.txt`, `Perso/rib.txt`,
`Perso/analyses.txt`, `Docs/Paie/bulletin-03-2025.txt`) — passport, IBAN,
lab results, payslip. Correct: sensitive guard → `propose` ahead of any
rule; never auto-trashed; the IBAN and SIRET are extracted as validated ids.

**Invoice set** (`Docs/Factures/facture-2025-*.pdf`) — carries the
Luhn-valid SIREN. Correct: id extracted and validated, entity resolved,
`route` at strength 3. A grader may also plant a plausible-looking 9-digit
number that fails Luhn anywhere in a file and check it is NOT an id.

**Residual set** (`Docs/Scans/scan-*.pdf`, `photo-*.jpg`,
`vieille-lettre-*.doc`, `Docs/notes.txt`) — no-text PDFs (needs_vision),
JPEG magic with no pixels, legacy Word binaries, prose with no rule.
Correct: no crash on any of them; nothing invented; they end `residual`
or `needs_vision`, never routed on their names.

## Pipeline traps (pinned v1 bugs not tied to one file)

**Incremental memory** — kill apply mid-`--execute` (or simulate: the
dangling symlink fails an entry mid-list). Correct: every action already
performed has its memory line written and its `result` stamped in
routing.json at the moment of interruption; `--resume` finishes the rest
without redoing or double-recording anything.

**by_path index** — decide differently about the same path in two passes.
Correct: `Memory.by_path` keeps the LAST record per path;
`stats` reports `distinct_files = len(by_path)`, not the line count.

**Vision barrier** — run route while any entry still has
`needs_vision: true` and empty text. Correct: exit 2 with the paths
listed; no triage columns written for unread bytes.

**Unanswered by name** — leave one selected file undecided through a full
pass. Correct: `--learn` reports it BY NAME, writes its memory line with
`decision: "unanswered"`, and the next collect selects it FIRST.

**Bench archived** — end a pass with `--learn`. Correct: `bench/` is moved
to `logs/<pass>/` (renders, routing.json and logs intact); it is never
rmtree'd, and the next pass starts on a fresh bench.

**Anchor check** — the grader's config lists an anchors file citing one
backticked path that no longer resolves. Correct: `--learn` prints a
warning naming the dead pointer; it never fails the pass, and it never
silently ignores it — a dead pointer is a fact that left the instructions
file and arrived nowhere.
